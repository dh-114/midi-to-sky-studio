# midi 转光遇（Sky）Sky Studio 曲谱

一个纯前端的网页小工具，把 MIDI 文件转成 Sky Studio 能导入的曲谱。

在线试用：<https://dh-114.github.io/midi-to-sky-studio/>

MIDI 全在浏览器里解析，不会传到任何服务器上去。

## 怎么用

1. 打开上面的在线版，或者把仓库下下来双击 `index.html`，都不用起服务器
2. 选一个 MIDI 文件
3. 挑要转的音轨，填「最大八度」「播放速度」和曲名，点「开始转换该音轨」
4. 页面会下载一个 `曲谱文件.txt`，导入 Sky Studio 即可

`test.json` 是一份 Sky Studio 导出的曲谱，可以拿来对输出格式。

## 说明

- 音域只取第 3 到第 5 个八度，映射到光遇那 15 个键上，超出去的音符直接丢掉。所以转之前先按原曲的音域把「最大八度」填对，一般填 4 或 5。
- 「播放速度」就是曲谱里的 bpm，网上抄来的谱子常见值在 450 附近，填多少看自己弹不弹得过来。
- 多轨 MIDI 可以选「所有音轨(合并)」，也可以只转其中一条轨。
- 输出结构跟 Sky Studio 的曲谱一致：`name`、`bpm`、`bitsPerPage`、`songNotes`，音符写成 `{"time": 毫秒, "key": "1KeyN"}`，N 是 0–14，按时间排好序。
- MIDI 解析和文件下载分别用的 CDN 上的 `@tonejs/midi` 和 `FileSaver.js`。页面空白或者点转换没反应，基本就是这两个没加载出来（断网、CDN 被墙之类）。

## 已知问题

- 只输出 `1Key0`–`1Key14`，没用到 `2Key` 那一组键位，所以听着高的音符会被压到 14 去。
- 下载的文件名固定是 `曲谱文件.txt`，转之前记得自己填曲名，不然后面分不清哪个是哪个。
- 转换逻辑就是照着光遇 15 键的排列硬写的，别的调式、别的谱面格式都没管。
